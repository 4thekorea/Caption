# 발표 통역 자막 도우미

**소규모(5~6명) 해외 기관 방문용 통역 도우미입니다.** 통역사를 부르기는 애매하고 방문을 안 할 수도 없을 때,
상대 기관의 **영어 발표를 한국어 자막으로 따라가고**, 끝에 **우리가 한국어로 질문하면 영어로 보여 주고 답변을 다시 한국어로** 보여 줍니다.
돌아와서는 남은 회의록으로 결과보고서를 씁니다.

- **바로 쓰기:** https://4thekorea.github.io/Caption/
- **현재 버전:** v0.8.1 (2026-11-16)
- **환경:** PC(노트북) 크롬 전용 — 태블릿·휴대폰은 지원하지 않습니다

## 현장 흐름

| 단계 | 말하는 사람 | 화면 |
|---|---|---|
| 1. 기관 발표 | 상대 (영어) | 슬라이드 + 한국어 자막 (말 끝 3~5초 뒤) |
| 2. 우리 질문 | 우리 (한국어) | 영어 번역 — **노트북을 상대 쪽으로** 돌려 읽게 함 |
| 3. 상대 답변 | 상대 (영어) | 한국어 자막 |
| 4. 귀국 후 | — | 회의록(질문·답변·화자별 요지) → 결과보고서 초안 |

## 현장 체크리스트

- **인터넷:** 우리 한국어 질문은 구글 음성인식을 씁니다 → 기관 와이파이가 없으면 **휴대폰 핫스팟**
- **마이크:** 외장 회의용 마이크를 테이블 가운데에 (노트북 내장 마이크는 멀리 있는 목소리에 약함)
- **질문 준비:** 핵심 질문은 미리 영어로 준비하고, 즉석 질문만 도우미로
- **양해 한마디:** "번역 프로그램을 쓰니 문장 사이를 잠깐 쉬어 달라" → 정확도·속도가 함께 좋아짐
- **협상·의전·계약**처럼 오역의 대가가 큰 자리에는 통역사를 쓰세요

## 무엇을 하나

| 기능 | 설명 |
|---|---|
| 자막 + 번역 | 말이 끝나고 약 3~5초 뒤 원문과 번역이 화자별 카드로 표시 |
| 발표자료 함께 보기 | PDF·PPTX·HTML을 왼쪽에 원본 모양 그대로, 리모컨으로 넘기기 |
| 자료 용어 교정 | 올린 자료 속 기관명·용어로 잘못 들린 말을 바로잡음 |
| 회의록 | 시각·슬라이드·화자·원문·번역 기록, 맨 위에 요점·화자별로 한 말·질문 요약. .txt / .md 저장 |
| 지연 대비 | 지연 신호등, 다른 탭 실행 감지, 밀리면 가벼운 모델로 자동 전환 |

## 두 가지 모드

| | ① 통역 | ② 시청 내부 회의 |
|---|---|---|
| 언제 | 해외 기관 브리핑, 우리 발표, 질의응답 | 비공개·민감한 내용이 오가는 내부 회의 |
| 영어 받아쓰기 | Whisper (노트북 안에서) | Whisper (노트북 안에서) |
| 한국어 받아쓰기 | 구글 음성인식 | Whisper (노트북 안에서) |
| 음성이 가는 곳 | **구글 서버로 전송** | **노트북 밖으로 나가지 않음** |
| 번역 | 크롬 내장 번역기 (노트북 안에서) | 없음 (한국어 자막 + 회의록) |

> 켜 두면 마이크에 들리는 주변 대화까지 기록합니다. 쓰지 않을 때는 **■ 종료**를 누르세요.

## 처음 쓸 때

1. 크롬으로 위 주소를 엽니다 (도우미 탭은 **하나만**).
2. 와이파이에서 **[⬇ Whisper 미리 받기]** — 처음 한 번 약 330MB를 받아 브라우저에 저장합니다.
3. 마이크 허용 창에서 **[허용]**.
4. 발표자료를 올리고 → ① 또는 ② 선택 → **[▶ 발표 시작]** → 끝나면 **Esc 두 번** → 회의록 저장.

자세한 사용법은 배포용 사용법 문서(PDF)를 참고하세요.

## 알려진 한계

- 실시간 통역이 아니라 **문장이 끝난 뒤** 표시됩니다 (짧은 문장 약 3초, 긴 문장 앞부분은 더 늦음).
- 주변의 작은 말소리, 고유명사는 틀리기 쉽습니다.
- HTML 파일을 내려받아 열면 마이크 허용 창이 반복해서 뜹니다 → **주소로 여세요.**
- 크롬 AI 요약(회의록의 '요점')은 노트북 조건(여유 공간 22GB, 메모리 등)에 따라 안 될 수 있습니다. 그때는 '화자별로 한 말'만 나옵니다.

## 기술 정보

- HTML·CSS·JS 한 파일, 서버·로그인 없음, 기록은 사용하는 노트북 브라우저에만 저장
- 부품(버전 고정): Transformers.js 3.8.1 (Whisper small/base, WebGPU), pdf.js 3.11.174, @aiden0z/pptx-renderer 1.4.0
- 크롬 내장 기능: 음성인식(구글), Translator API(한↔영), Summarizer API(요약, 지원 기기만)
- 버전별 변경 내역은 `index.html` 맨 위 주석에 있습니다
