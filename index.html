1발표자료

PDF · PPTX · HTML끌어다 놓거나 [파일 선택]. 원본 모양 그대로 보여 주고, 글자는 통역 참고로 씁니다. 파일은 이 기기 안에서만 엽니다.
원본과 똑같아야 하면 PDF가 가장 정확합니다(PPTX는 글꼴 등이 조금 달라질 수 있음). PPT(옛 형식)·HWP·Keynote는 PDF로 저장해서 올려 주세요.

올린 자료 없음.

발표자료나 참고자료를 올리면 여기에 기준 용어가 표시됩니다.

번역 비교 — 엔진별 번역을 나란히 (자료 용어 적용)

자동: PC 크롬이면 크롬 내장(품질·속도 가장 좋음), 아이패드 등은 허깅페이스 모델(한→영 약 110MB · 영→한 약 850MB, PC 전용·실험용). 번역은 두 엔진 모두 이 기기 안에서 처리됩니다. 와이파이에서 미리 받아 두세요.

5화자 · 화면

말한 언어로 자동 구분합니다: 한국어 → A, 영어 → B. 다른 사람이 말하면 1 2 3 키나 오른쪽 위 화자 칩을 누르세요(방금 나온 카드도 함께 바뀜). 언어가 바뀌면 다시 자동, 0 은 바로 자동으로.

발표 중 키 · 리모컨

  • 리모컨(프레젠터): 다음/이전 버튼이 보내는 PgDn PgUp·→ ← 로 넘어갑니다. 슬라이드쇼 버튼(F5)은 무시(새로고침 방지), 화면 끄기 버튼(B .)은 슬라이드만 까맣게(통역 칸은 유지), Esc 는 2초 안에 두 번 눌러야 종료.
  • 다음 → PgDn Space ↓ · 이전 ← PgUp ↑ · 처음/끝 Home End · 화면 오른쪽 터치=다음, 왼쪽 ⅓=이전
  • 화자 1 2 3 · 자동 0 · 언어 전환(가벼운 모드) L · 방금 문장 중요 M
  • F 전체화면 · C 통역 칸 숨김/보임 · W 칸 폭 · + − 통역 글자
  • HTML 자료는 자료 안의 목차·버튼도 그대로 작동합니다(문서 안 링크는 스크롤, 인터넷 링크는 새 탭).
  • 기록은 말할 때마다 이 기기 브라우저에 자동 저장됩니다. 창이 꺼져도 다시 열면 이어서 할 수 있습니다.
